# Plan: ESP32-C3-MINI Pin Update + Dual-Transport Modbus TCP (WiFi/Ethernet)

**Target board:** ESP32-C3-MINI / ESP32-C3-DevKitM-1  
**Firmware scope:** `firmware/transmitter-single-core` (single-core layout)  
**New feature:** Modbus TCP over WiFi or W5500 Ethernet, selectable via frontend  
**New feature:** 128x64 OLED display for local weight/status readout

---

## 1. HX711 Pin Update

Current:
- `LOADCELL_DOUT_PIN` = 2
- `LOADCELL_SCK_PIN` = 4

New:
- `LOADCELL_DOUT_PIN` = 6
- `LOADCELL_SCK_PIN` = 5

Reason: pins 5/6 are reserved for W5500 Ethernet module  
(W5500: SCK=0, MISO=2, MOSI=3, CS=4; HX711: DT=6, SCK=5).

File: `firmware/transmitter-single-core/src/config.h`

---

## Decision Needed

**Transport selection persistence:**

Option A (Recommended): Persist transport mode in NVS via `SettingsStore`. On boot, apply saved mode automatically.

Option B: Always start WiFi, allow runtime switch via frontend. WiFi is default fallback if Ethernet fails.

Recommendation: Option A, as it matches existing pattern for WiFi credentials and calibration.
